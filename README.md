# Institute of Digital Risk (IDR)

A submission-ready brand and homepage project for the **Institute of Digital Risk (IDR)**, an industry-led training and deployment institute focused on digital, cyber, technology, and AI risk capability. The project includes a custom SVG logo system and a responsive single-page website built with vanilla HTML, CSS, and JavaScript.

## Features

- Custom **IDR logo system** in SVG
  - icon-only version
  - full wordmark version
- Responsive single-page homepage
- Sticky navigation bar
- Smooth scrolling section links
- Mobile hamburger menu
- Hero section with clear calls to action
- About section with institutionally credible messaging
- Service pillars for:
  - Academy
  - Innovation & Incubation
  - Advisory Services
- Visual **train → hire → innovate → deploy** pipeline
- Community / audience section
- Contact form UI and register-interest CTA
- Accessible focus states and readable contrast
- Subtle reveal-on-scroll animations using vanilla JavaScript
